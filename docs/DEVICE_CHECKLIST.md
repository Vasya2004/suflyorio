# Приёмка на iPhone 14 Pro Max

**Статус: не выполнена.** Полный Xcode не установлен, приложение пока не собрано и не установлено на iPhone.

После установки заполнить дату, версию Xcode, фактическую iOS и результат каждой проверки. Нельзя заменять физическую проверку камеры прохождением тестов в симуляторе.

## Подготовка

- [ ] Проект собирается без ошибок; у обоих targets одна Personal Team.
- [ ] iPhone 14 Pro Max / iOS 26.6.1 подключён, Developer Mode включён.
- [ ] App Icon и имя «Суфлёр» видны на домашнем экране; приложение запускается без кабеля.
- [ ] Product → Test: проходят 13 тестов ядра и 4 теста SwiftData/восстановления.

## Тексты и чтение

- [ ] Первый запуск содержит ровно один пример; повторный запуск не создаёт копию.
- [ ] Создание, изменение названия/текста, поиск, дублирование и удаление работают.
- [ ] Кириллица, пустые строки, эмодзи и длинный сценарий отображаются корректно.
- [ ] Вставка и импорт UTF-8/UTF-16 `.txt` работают; неподдерживаемый/слишком большой файл даёт понятное сообщение.
- [ ] Редактирование → закрытие → повторный запуск сохраняет текст. После удаления всех сценариев пример не возвращается.
- [ ] Шрифт, интервал, ширина, затемнение и скорость сохраняются после перезапуска.
- [ ] Репетиция не создаёт видео. Dynamic Island не закрывает текст; все кнопки доступны при увеличенном системном шрифте.
- [ ] Пауза, продолжение, ручная перемотка и возврат к началу не дают скачка текста.

## Видео и звук

- [ ] Отсчёт 0/3/5 секунд работает. Отмена отсчёта не создаёт видео.
- [ ] Прокрутка стартует после камеры. Красный индикатор соответствует фактической записи.
- [ ] Видео вертикальное 1080×1920 после применения track transform, 30 fps, H.264/AAC.
- [ ] Превью точно соответствует сохранённому кадру 9:16. Проверено на предмете возле краёв кадра.
- [ ] Текст и контролы отсутствуют в файле. Проверить русскую надпись в сцене: запись по умолчанию незеркальная, настройка зеркальности работает только для селфи.
- [ ] Проверены фронтальная и основная камеры; во время записи переключение заблокировано.
- [ ] Голос слышен через встроенный микрофон, звук синхронен с изображением. Хлопок в начале и конце 10-минутного ролика не показывает заметного рассинхрона.
- [ ] Пауза текста и достижение его конца не прекращают запись. Стоп создаёт отдельный дубль.
- [ ] 10 последовательных коротких дублей сохранены и воспроизводятся без пропусков и перезаписи.
- [ ] Один 10-минутный дубль сохранён, воспроизводится полностью, прокрутка плавная; отмечены температура и расход батареи.

## Ошибки и сохранность

- [ ] Камера запрещена, микрофон запрещён, оба запрещены: нет ложного индикатора записи; переход в настройки и повторная попытка работают.
- [ ] Быстрые многократные нажатия Start/Stop не создают дубликаты или зависшее состояние.
- [ ] Входящий звонок, блокировка, уход в фон и переключение аудиоустройства завершают доступный дубль. Возврат не запускает новую запись.
- [ ] Автоблокировка отключена при чтении/съёмке и восстановлена после выхода.
- [ ] Недостаток памяти до старта даёт ошибку. Сбой при завершении не помечает повреждённый файл как успешный.
- [ ] Повторный запуск возвращает пригодный незавершённый дубль и не дублирует его. Повреждённые файлы не удаляются автоматически.
- [ ] Экспорт в «Фото» разрешён/запрещён; отказ не удаляет дубль. После выдачи доступа повторный экспорт работает.
- [ ] «Поделиться» сохраняет/передаёт реальный файл со звуком. Удаление локального дубля не удаляет копию в «Фото».
- [ ] Повторный Run поверх приложения с прежней подписью сохраняет тексты, настройки и дубли.

Нехватку места и критический нагрев не следует искусственно создавать заполнением или перегревом личного телефона. Ошибочные ветки проверять через тестовую конфигурацию/отладчик, физическое поведение — когда соответствующее условие возникает естественно. Отметить отдельно, какие сценарии проверены инъекцией ошибки, а какие на устройстве.
